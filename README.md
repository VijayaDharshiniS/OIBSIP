# Oasis Infobyte Data Analytics Internship

## Task 1: Exploratory Data Analysis on Retail Sales Data

### Objective
To analyse retail sales data and identify sales trends, customer behaviour patterns, and useful business insights.

### Tools and Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

### Dataset
The dataset contains transaction details, dates, customer IDs, gender, age, product category, quantity, price per unit, and total amount.

### Analysis Performed
- Dataset inspection and missing-value checking
- Descriptive statistics: mean, median, mode, and standard deviation
- Monthly and quarterly sales trends
- Sales analysis by gender and age group
- Revenue by product category
- Quantity sold by product category
- Correlation heatmap
- Average transaction value by gender

### Key Findings
The analysis explores how revenue changes over time, how sales are distributed across customer groups, and which product categories contribute to revenue and sales volume.

### Business Recommendations
1. Maintain suitable stock levels for categories with higher sales.
2. Use monthly and quarterly trends to plan promotional campaigns.
3. Develop targeted offers based on observed customer-group purchasing patterns.
4. Test product bundles to increase average transaction value.
5. Collect individual product names and profit data for more detailed product-level analysis.

### Limitation
The available dataset does not contain individual product names. Therefore, the top 10 best-selling individual products could not be identified; the analysis instead focuses on product categories.

### Conclusion
This project demonstrates exploratory data analysis using Python to understand retail sales patterns, customer demographics, and category performance. The findings can support data-driven sales planning and marketing decisions.
