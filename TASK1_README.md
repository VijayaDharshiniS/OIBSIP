# Retail Sales Exploratory Data Analysis (EDA)

## Project Overview
This project performs Exploratory Data Analysis (EDA) on a retail sales dataset to understand sales performance, customer purchasing patterns, and product category trends.

## Objective
- Inspect and clean the retail sales dataset.
- Calculate descriptive statistics.
- Analyze sales trends over time.
- Explore customer demographics and product categories.
- Identify useful business insights and recommendations.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Workflow
1. Load and inspect the dataset.
2. Check and handle missing or inconsistent data.
3. Calculate descriptive statistics.
4. Analyze monthly sales trends.
5. Explore customer age and gender patterns.
6. Compare product categories and revenue.
7. Visualize relationships and identify insights.
8. Provide business recommendations.

## Key Outcomes
The analysis helps identify sales patterns, customer purchasing behaviour, and product categories that contribute to retail revenue. These insights can support data-driven business decisions.

## Files
- `Vijayadharshini_Task1.ipynb` — Jupyter Notebook containing the analysis.
- `retail_sales_dataset.csv` — Dataset used for the project.

## How to Run
1. Install Python and Jupyter Notebook.
2. Install the required libraries: pandas, numpy, matplotlib, and seaborn.
3. Open `Vijayadharshini_Task1.ipynb` in Jupyter Notebook.
4. Keep the dataset in the appropriate folder and run the notebook cells in order.
